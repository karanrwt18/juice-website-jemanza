🌟 About The Project

JINMAZA is a modern beverage brand website created to present a premium juice and fruit-drink experience on the web.

The design focuses on a combination of:

🍓 Rich fruit visuals

🧃 Product-focused layouts

✨ Smooth animations

🎨 Vibrant beverage-inspired colours

📱 Responsive mobile design

🛒 E-commerce-style shopping experience

💫 Interactive user interface

The goal of the project is to make the website feel like a real commercial beverage brand, rather than a basic static college/student website.

🎯 Project Goals

The website was designed around four main ideas:

01 — Freshness

Use bright fruit imagery, energetic layouts and refreshing visual elements to communicate freshness.

02 — Premium Branding

Use large typography, modern spacing, rounded cards, shadows, gradients and product-focused compositions.

03 — Interaction

Add animations, hover effects, scroll reveals, product interactions and cart functionality.

04 — Responsive Experience

Make the complete website usable on desktop, laptop, tablet and mobile devices.
